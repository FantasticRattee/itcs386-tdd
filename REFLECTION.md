## Confirmed learning note: if statements and tests

This is supporting material from our discussion, not an additional worksheet
question or a complete replacement for the six required answers.

An `if` statement makes a decision based on a condition we write ourselves, and
that logic may be correct or incorrect. For a test, we prepare an input and an
expected output. Basically, we have both the input and the answer we expect, so
we can compare the program's actual output with that answer to check whether it
behaves correctly for that input.
